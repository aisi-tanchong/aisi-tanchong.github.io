## 🚀 我的旗舰项目：AISI Protocol

**AISI（原子化智能服务接口）** 是我主导设计的一个接口协议，旨在解决AI智能体与外部服务集成的标准化难题。

- **🌐 [访问官方协议文档网站](https://aisi-tanchong.github.io)**
- **📦 [访问国内Gitee镜像仓库](https://gitee.com/aisi-tanchong/aisi-protocol)**

### 协议核心理念
传统的API对于AI来说过于复杂和“黑盒”。AISI协议通过**原子化（Atomization）** 和**声明式组合（Declarative Composition）** 的思想，让AI能够像搭积木一样理解和调用服务能力。

### 快速了解
| 特性 | 描述 |
| :--- | :--- |
| **🔬 原子操作** | 将复杂业务拆解为单一、可描述的原子操作。 |
| **📄 统一描述** | 使用JSON Schema标准化每个操作的输入、输出。 |
| **🧩 可视化组合** | 支持通过DAG（有向无环图）将原子操作组合成工作流。 |
| **⚙️ 内置状态机** | 为异步操作提供标准的状态跟踪与管理。 |

### 应用场景举例
- **🤖 智能客服自动化**：自动处理工单、查询知识库、邮件回复。
- **🛒 电商订单流水线**：自动编排库存检查、支付、物流等服务。
- **📊 智能数据分析**：连接多个数据源，执行清洗、分析与报告流程。
